# Taller Autos

Panel de gestión de taller hecho con Vue 3 + Quasar + Vite.

## Comandos

```bash
npm install
npm run dev      # desarrollo
npm run build    # producción
```

## Estructura

```
src/
├── components/   componentes reutilizables (PageHeader, StatusChip)
├── css/          app.scss (estilos globales) y quasar-variables.sass (colores de marca)
├── data/         datos de ejemplo (mock.js)
├── layouts/      MainLayout.vue (header + sidebar)
├── pages/        una página por ruta
├── router/       rutas
└── main.js
```
